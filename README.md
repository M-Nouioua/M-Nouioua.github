# Dr. Nouioua Mourad — 3D Portfolio

A dark, immersive 3D portfolio website built with React, Three.js, and Tailwind CSS. Features a rotating wireframe icosahedron hero effect, real Google Scholar publication data, and small decorative 3D elements throughout each section.

## Live Demo

[https://mourad-nouioua.github.io/portfolio](https://mourad-nouioua.github.io/portfolio)

## Features

- **3D Hero Effect** — Rotating wireframe icosahedron with mouse-reactive tilt, scroll-driven animation, and nested dual-layer geometry
- **Real Publication Data** — 9 papers fetched from Google Scholar with citation counts and direct links
- **Google Scholar Stats** — 1002+ citations, h-index 17, i10-index 20, 50+ publications
- **Floating 3D Decorations** — Small icosahedron elements throughout each page section
- **Fully Responsive** — Mobile-friendly navigation and layouts
- **Smooth Animations** — Scroll-triggered entrance animations on all sections

## Tech Stack

- React + TypeScript + Vite
- Three.js (3D icosahedron effect)
- Tailwind CSS
- Lucide React (icons)

## Deploy to GitHub Pages

Pushing to the `main` branch triggers the GitHub Actions workflow that automatically builds and deploys to GitHub Pages.

Make sure GitHub Pages is enabled in your repository settings:
1. Go to **Settings > Pages**
2. Set **Source** to "GitHub Actions"
